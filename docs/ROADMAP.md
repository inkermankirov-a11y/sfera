# Roadmap

## Этап 0 — фундамент

- структура monorepo;
- архитектурные контракты;
- Module Registry;
- базовые TypeScript-типы.

## Этап 1 — Core

- Workspace;
- Objects;
- Object Types;
- Fields;
- Relations;
- Events;
- Views;
- History.

## Этап 2 — первый вертикальный сценарий

- Tasks;
- Weekly Planner;
- простой Dashboard.

Цель: пользователь может создать задачу, распределить её по неделе, перемещать и завершать.

## Этап 3 — персональная база

- Collections;
- Journal;
- Search;
- Files.

## Этап 4 — календарь

- единое календарное представление объектов с датами.

## После MVP

Отложено:

- AI Assistant;
- semantic search;
- graph view;
- automation builder;
- habits;
- finance;
- health;
- shared workspaces;
- real-time collaboration;
- native mobile/desktop;
- offline synchronization;
- plugin marketplace;
- public module SDK;
- third-party integrations.
