# Responsive UX — обязательный контракт SFERA

SFERA проектируется одновременно для ПК и телефона. Мобильная версия не является уменьшенной копией desktop-интерфейса.

## Базовый принцип

Одна кодовая база и одна модель данных, но разные композиции интерфейса по ширине экрана.

- Desktop: постоянная боковая навигация, широкая рабочая область, detail drawer справа.
- Tablet: сворачиваемая навигация, рабочая область на всю доступную ширину.
- Mobile: нижняя навигация, полноэкранные экраны/листы вместо постоянных боковых панелей.

## Контрольные ширины

- 1280+ px: desktop wide
- 900–1279 px: desktop/tablet
- 600–899 px: tablet
- <600 px: mobile

Компоненты не должны зависеть только от user-agent. Адаптация строится по доступной ширине контейнера/viewport.

## Touch UX

- интерактивная зона: не менее 44x44 px;
- действия, требующие hover, обязаны иметь touch-эквивалент;
- drag & drop не должен быть единственным способом выполнить действие;
- destructive actions скрываются за дополнительным подтверждением/меню.

## Tasks — Desktop

Структура:

1. Sidebar приложения.
2. Header модуля Tasks.
3. Quick Add.
4. Переключатели представлений/фильтры.
5. Список задач.
6. Detail Drawer справа при выборе задачи.

Выбранная задача не уводит пользователя со списка.

## Tasks — Mobile

Структура:

1. Compact header: название + поиск/действия.
2. Горизонтальные chips представлений.
3. Quick Add.
4. Список задач на всю ширину.
5. Floating action button или нижняя кнопка создания.
6. Bottom navigation приложения.

При открытии задачи detail drawer превращается в полноэкранный detail screen / bottom sheet.

## Действия задачи на mobile

Строка задачи показывает только главное:

- checkbox;
- title;
- date;
- priority/relations indicator при наличии.

Дополнительные действия доступны по tap/long press/overflow menu.

## Weekly Planner

Desktop:
- 7 колонок дней + блок без даты;
- drag & drop;
- связи/детали открываются сбоку.

Mobile:
- не пытаться уместить 7 узких колонок;
- переключатель дней или горизонтальный scroll/snap;
- быстрый переход «Сегодня»;
- drag & drop дополняется командами «Перенести в…».

## PWA

SFERA должна быть installable как PWA:

- manifest;
- theme color;
- standalone display;
- app icons;
- safe-area support;
- базовый service worker/cache strategy.

На MVP — online-first с локальным кэшем. Полный offline-first и разрешение конфликтов откладываются.

## Проверка перед merge

Каждый пользовательский экран проверяется минимум на:

- 1440x900
- 1024x768
- 768x1024
- 390x844
- 360x800

Не допускаются:
- горизонтальный scroll страницы;
- обрезанные основные действия;
- элементы меньше touch target;
- desktop-only hover;
- модальные окна, не помещающиеся в viewport.
