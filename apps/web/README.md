# @sfera/web

Пользовательское веб-приложение СФЕРА.

## UX-контракт

Интерфейс проектируется одновременно для ПК, планшета и телефона.

- одна кодовая база;
- responsive layouts;
- mobile UI — отдельная композиция, а не масштабированный desktop;
- PWA / installable web app;
- online-first + local cache на MVP;
- touch targets не менее 44x44 px.

Подробно: [Responsive UX](../../docs/RESPONSIVE_UX.md).
